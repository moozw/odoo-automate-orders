Both settings are **off by default**; the module does nothing until one is
enabled.

**Sales → Configuration → Settings → Auto-confirm delivery & invoice**
  Validate the delivery and post the invoice when a sale order is confirmed, and
  block confirmation when stock is short.

**Purchase → Configuration → Settings → Auto-confirm receipt & bill**
  Validate the receipt and post the vendor bill when a purchase order is
  confirmed.

Both are per company, not per user, per order or per warehouse.
